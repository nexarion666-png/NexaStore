# NexaStore

A personal app marketplace for Nexarion's applications.

## Project structure

- `website/` — React + TypeScript website for browsing and downloading apps.
- `android/` — Android app-store client (planned).
- `backend/` — shared app catalogue and release metadata (planned).

## Development plan

1. Build the website.
2. Set up the shared app catalogue.
3. Add app details, screenshots, versions, changelogs, and download links.
4. Build the Android client.
5. Deploy and test both clients.

Do not commit passwords, private signing keys, or secret API credentials to this repository.
